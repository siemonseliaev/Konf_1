# Эмулятор Virtual File System (VFS)

Графическое приложение на Python, эмулирующее работу командной строки для взаимодействия с виртуальной файловой системой (VFS).

##Особенности

* **Графический интерфейс в стиле терминала:** Черный экран с белым текстом и встроенной строкой ввода.
* **Кастомное приглашение ко вводу:** Отображение текущего VFS-архива в формате `[my_vfs.tar]$ `.
* **Безопасный парсинг команд:** Использует модуль `shlex` для корректной обработки аргументов с кавычками и пробелами.
* **Валидация и обработка ошибок:** Вывод сообщений о синтаксических ошибках, незакрытых кавычках и неверных аргументах.

##Поддерживаемые команды

| Команда | Аргументы | Описание |
| :--- | :--- | :--- |
| `help` | — | Вывод справки по доступным командам |
| `ls` | Вывести список файлов (заглушка) |
| `cd` | Сменить директорию (требует ровно 1 аргумент, заглушка) |
| `exit` | — | Завершить работу приложения |

##Требования

* **Python 3.x**
* Стандартные библиотеки `tkinter` и `shlex` (входят в базовую поставку Python)
